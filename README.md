# Fernweh

An AI-first travel commerce backend: natural-language search with zero dead
ends, personalized re-ranking with business rules, and an autonomous content
enrichment pipeline — a Go monorepo (no framework) on PostgreSQL, Redis,
Asynq, and OpenTelemetry/Jaeger, with Docker Compose parity between local and
production.

> for what's being built and why.
