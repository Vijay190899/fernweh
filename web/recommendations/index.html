Bounded, not unlimited

The business term is capped, so a promoted listing can tip a close call between comparable stays but cannot bury a clearly better match. Two tests hold that line from both directions.

Disclosed, not hidden

Promoted results carry a visible label and a reason. If commercial interest moved a result up the page, the page says so.

Explainable by design

A learned ranker would score better. It would also make the bound much harder to guarantee, so the linear model is the baseline any replacement has to beat while keeping it.
