01

Understanding
beats filtering.

A traveller writes one sentence. A language model turns it into a strict, validated intent: destination, month, budget per night, party, the amenities that matter. Then it queries live inventory.

When the model is unavailable, over budget, or slow, a deterministic parser answers instead and the response says which path served it. Search never fails because an AI provider failed.

Ordered for you.

Every click, dwell and booking becomes a weighted signal. Those build a session profile, and the profile reorders results. Each card carries the reason it ranked where it did.

Merchandising rules sit alongside personal fit, bounded so a promoted listing can tip a close call but never bury a clearly better match. Promotions are always disclosed on the card.

03

Inventory that
repairs itself.

Supplier feeds arrive with holes: no description, no amenities, nothing to rank on. A scanner finds them, a queue distributes the work, and a worker writes copy grounded strictly in facts already on the listing. No invented pools, no invented views.

Every write is audited with its before, its after, and whether a model or a template produced it.

04

Built to be
taken apart.

Four Go services, no web framework, one trace per request that follows a job across a Redis queue into a worker. Postgres, Redis, Asynq, OpenTelemetry, Betterstack. The same Compose file runs locally and in production.

The AI is optional at runtime

One client owns model access and meters spend against a daily budget. Remove the key and every feature still works, on deterministic paths, and the badge above your results says so.

No dead ends, disclosed

Over-constrained queries relax in a fixed order: style, amenities, rating, budget by 15 then 30 percent, dates, place. Whatever was relaxed is shown to the traveller.

One trace across the queue

Trace context is serialised into the task payload, so a scan, its Redis hop, the worker and the database write appear as a single trace. Every search response links its own.

Measured, not asserted

15,498 requests across five load levels, zero errors, p95 flat at five milliseconds from 25 to 400 requests per second. The generator that produced those numbers is in the repository.
