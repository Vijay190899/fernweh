⚡ The AI is optional at runtime

Intent extraction and content generation go through one LLM door with a daily budget cap. No key, cap hit, provider down? Deterministic fallbacks answer instead — search never breaks, and the response tells you which path served it (watch the engine badge).

🪜 Zero dead ends, honestly

Over-constrained queries relax stepwise — style → amenities → budget +15/30% → dates → place — and every relaxation is disclosed in the yellow banner. No silent result-stuffing.

🔍 One trace across the queue

Trace context rides inside Asynq task payloads, so scan → Redis → worker → Postgres shows as a single Jaeger trace. Each search response carries its trace id — click it.

🛡️ Safe to run in public

Per-IP token buckets, body-size caps, a platform-wide daily LLM budget in Redis, security headers, and internal services that the internet can't reach.
