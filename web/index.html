⚡ The AI is optional at runtime

Intent extraction and content generation go through one LLM door with a daily budget cap. No key, cap reached, provider down? Deterministic fallbacks answer instead. Search never breaks, and the response says which path served it (watch the engine badge).

🪜 Zero dead ends, honestly

Over-constrained queries relax stepwise: style, then amenities, then budget by 15/30%, then dates, then place. Every relaxation is disclosed in the yellow banner. No silent result stuffing.

🔍 One trace across the queue

Trace context rides inside Asynq task payloads, so scan, Redis, worker, and Postgres show as a single Jaeger trace. Each search response carries its trace id. Click it.

🛡️ Safe to run in public

Per-IP token buckets, body-size caps, a platform-wide daily LLM budget in Redis, security headers, and internal services the internet cannot reach. Logs ship to Betterstack when configured.
