The Products

01 · Search

Understanding
beats filtering.

One sentence becomes a validated intent, then a query against live inventory. Over-constrained searches relax in a fixed order and say exactly what they changed, so a traveller never meets an empty page.

02 · Recommendations

Ordered for you.
Still honest.

Clicks and bookings build a session profile that reorders results, and every card carries the reason it ranked where it did. Merchandising is bounded, so a promotion can tip a close call but never bury a better match.

03 · Content Enrichment

Inventory that
repairs itself.

Supplier feeds arrive with holes. A scanner finds them, a queue distributes the work, and a worker writes copy grounded strictly in facts already on the listing. Every change is audited.
