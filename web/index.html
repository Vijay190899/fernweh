Built to be
taken apart.

A Go monorepo with no web framework, four services, and one trace that follows a job across a Redis queue into a worker. The same Compose file runs on a laptop and in production.

Services
4Gateway, search, ranking, enrichment. One Go module, no framework.
Load tested
400Requests per second, 15,498 requests, zero errors, p95 flat at 5 ms.
Fallback parse
14.8 µsThe deterministic path, used whenever the model is unavailable.
Dead ends
0Guaranteed by a relaxation ladder whose last rung has no constraints.

The AI is optional at runtime

One client owns model access and meters spend against a daily budget. Remove the key and every feature still works on deterministic paths, and the response tells you which path served it.

One trace across the queue

Trace context is serialised into the task payload, so a scan, its Redis hop, the worker and the database write appear as a single trace in Jaeger. Every search response links its own.

No QA team

Table-driven tests cover every decision path, benchmarks cover the hot ones, and a load generator produces the numbers above. The suite and the traces are the QA.

Built with Claude Code

Specs first, invariants in CLAUDE.md, one reviewed pull request per capability. The build log lists the bugs the model wrote and exactly how each was caught.
